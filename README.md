# DejaVu Softworks

Static website for Another 2D Platformer.

## GitHub Pages and app-ads.txt

For AdMob to discover `app-ads.txt`, GitHub Pages must serve this repository at
the root of the host: `https://zeroretro.github.io/app-ads.txt`.

Use a GitHub user site repository named `ZeroRetro.github.io`, or configure a
custom domain. A project site such as `zeroretro.github.io/dejavu-softworks/`
does not place the file at the hostname root required by AdMob.
